# Nebel OS 1.4.4 — «Aurora» (план)

Направление от владельца (2026-09-19):
почва под VR (Quest 3 позже, сейчас — фундамент), беспроводной экран,
режимы DUO, **оптимизация (критично)**, тянуть решения конкурентов,
обновления и исправления. Без миграции с Fedora bootc.

## 1. VR-почва (аппаратно-нейтрально, переживёт смену железа)

- **WiVRn 26.6.2 + Monado** — уже в репах Fedora 44, собраны под aarch64.
  Ставим в образ (`36-install-vr.sh`), сервер выключен по умолчанию.
- `nebel-vr.service` — включается из UI (флаг `/etc/nebel/vr-enabled`), поднимает
  `wivrn-server`. Выключаемый, не трогает игровую сессию, когда off.
- OpenXR runtime зарегистрирован через xr-hardware / стандартные пути Monado.
- **Виртуальный дисплей WiVRn** = беспроводной экран: при коннекте шлема
  поднимается виртуальный монитор, gamescope-сессия может туда выводиться.
  Для DUO: верхняя панель / кинотеатр стримится на шлем.
- «Режим кинотеатра» v1: виртуальный большой экран (config WiVRn
  `virtual-display`), отдельная gamescope-сессия для медиа поверх игры.

## 2. Оптимизация (критично)

- **scx_lavd** (sched-ext BPF-скедулер из pocknix) — НЕ default. Opt-in
  сервис `nebel-scx.service` + переключатель в UI. Осторожно: gamescope на
  SCHED_RR у нас вызывал полный хэнг (SCHEDULER_NOTES.md) — scx_lavd другой
  механизм (BPF, без RT-threads), но включать сначала только вручную/для теста.
- Кандидаты на пробу после scx: SDR104 sdhci-msm (kernel-патч, в
  armada-packages), per-game FEX preset.

## 3. Тянем решения конкурентов

- **Экспорт/импорт per-game твиков** (pocknix: JSON-шаринг конфигов) —
  game-tweaks.json уже есть, добавить export/import в plugin.
- **Per-game FEX preset** (accuracy vs speed) — UI + game-launch hook.
- SMB-шара из UI — отложено (Syncthing есть; SMB добавим с format-SD пачкой).
- Format SD из гейм-мода — отложено (нужен on-device тест).

## 4. Исправления

- **Wi-Fi не сохраняется** (жалоба 18.09 после переустановки): разбор
  NetworkManager/iwd, autoconnect-профиля. Приоритет — высокий.
- Остальное из сессионного лога по мере подтверждения на устройстве.

## Не входит (на потом)

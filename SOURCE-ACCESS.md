# Source access and licensing

The public repository is the image skeleton. Implementation and build carriers
are maintained privately. Private Git hosting does not change a component's
license, and the root LICENSE.md is not replaced with a proprietary license.

## Release source downloads

Each published release must include a source index identifying the exact binary
version, corresponding source archives, hashes, upstream licenses and build
instructions. Downloadable GPLv3-covered binaries must have equivalent source
download access, with directions next to the image and installer downloads.
An unavailable future URL or a source RPM containing only a download recipe
does not meet this release gate.

Only required covered source and notices are distributed. Access to the whole
private Git repository, signing keys, registry credentials and unrelated
independent work is not required or offered by this document.

## Written offer for GPLv2-covered components

For GPLv2-covered object code distributed in a Nebel release with this offer,
Ga1dz1 offers any third party a complete machine-readable copy of its
corresponding source, including Nebel modifications and the scripts used to
control compilation and installation, under the applicable GPL terms.

This offer remains valid for at least three years after the last distribution
of the covered release with this offer. Electronic source delivery is free.
If physical delivery is requested, any charge is limited to the actual cost
of physically performing source distribution.

Request it through the project's [GitHub issues](https://github.com/Ga1dz1/nebel/issues),
using the title `Source request` and identifying the release/image digest and
components requested. Do not include passwords, tokens, purchase evidence or
private Steam account information. This offer is not limited to supporters or
to the original recipient and does not restrict rights granted by the GPL.

For GPLv3-covered downloadable binaries use the release's equivalent-download
source index; the written offer above is not a substitute for that access.

## Candidate status

This document alone is not proof that an unpublished candidate complies with
all licenses. Before publication, its required source inventory, complete
archives and actual download routes must be verified. Components retain their
own license terms, including notices and obligations of permissively licensed
and firmware packages.
